# TrustVault
## Secure Sharing, Smarter Access, Verifiable Accountability

TrustVault is a secure document-sharing web application built using Python, Flask, and SQLite.

### Features
- User authentication
- Owner and Viewer roles
- Secure document uploading and sharing
- Revoke document access
- Block unauthorized document access
- Admin activity logs

### Technologies Used
- Python
- Flask
- SQLite
- HTML and CSS

### How to Run
1. Install the required Python packages.
2. Open the project folder in VS Code.
3. Run `python app.py` in the terminal.
4. Open `http://127.0.0.1:5000` in your browser.
